# Albeek Restaurant POS

A restaurant and fast-food point-of-sale project concept.

## Project scope

The portfolio describes order handling with kitchen-display workflows and thermal receipt printing.

## Technologies listed in the portfolio

- React 19
- Electron
- Kitchen display system (KDS)
- ESC/POS thermal printing

## Status

This repository currently contains project documentation only. Source code, printer integrations, and production-use evidence are not included.
